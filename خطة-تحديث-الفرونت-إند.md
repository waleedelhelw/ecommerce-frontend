## 1. نظرة عامة

### ملخص التغيير الجذري
تم إعادة كتابة نظام الدفع بالكامل في الباك إند. بدلاً من model واحد (`Payment`) لكل طلب، دلوقت كل طلب عنده **array من `OrderPayment`**. ده يضيف:

- **PaymentTarget**: Platform (افتراضي) أو Seller (تحويل مباشر للتاجر)
- **دفعات متعددة**: دفع مقدم + باقي (installment)
- **حالة لكل دفعة**: Pending → WaitingConfirmation → Confirmed → Completed
- **رفع إيصال لكل دفعة**: على مستوى `paymentId` مش `orderId`

### الـ Roles المتأثرة
| الـ Role | التغييرات |
|----------|-----------|
| 🟢 **Customer** | إنشاء طلب (حقول جديدة) + رفع إيصال لكل دفعة + عرض `payments` array |
| 🟡 **Seller** | تأكيد/رفض Self Mode payments + CRUD payment methods + ملخص مالي محدث |
| 🔴 **SuperAdmin** | تأكيد/رفض Platform payments (لكل دفعة في الـ array) |

## ملاحظات مهمة للفريق

1. **الطلبات القديمة:** الطلبات اللي اتعملت قبل التحديث مش هيبقى فيها `payments` array. تأكد من:
   ```javascript
   const payments = order.payments || [];
   // أو
   const payments = Array.isArray(order.payments) ? order.payments : [];
   ```

2. **الفرق بين OrderStatus و PaymentStatus:** متلخبطش بينهم. الـ Order عنده `OrderStatus` (PendingPayment, Processing, الخ) وكل دفعة عنده `PaymentStatus` (Pending, WaitingConfirmation, الخ).

3. **رفع الصور:** الـ API بياخد `receiptImageUrl` كـ string. محتاجين نرفع الصورة على Cloudinary الأول (موجود في `utils/cloudinary.js`) وبعد كده نبعت الـ URL.

4. **Self Mode والعمولة:** التاجر في Self mode المفروض يدفع العمولة بره المنصة. النظام بيسجل الـ commission كـ transaction تقريرية. مفيش خصم أوتوماتيكي.

5. **COD:** دايماً `paymentTarget = Seller`. مفيش حاجة اسمها "رفع إيصال" لـ COD. الدفع يتم كاش عند الاستلام.

6. **التوافق مع النسخة القديمة:** أي كود بيشير لـ `order.payment` لازم يتغير لـ `order.payments?.[0]` أو يتعامل مع الـ array.

7. **Seller Payment Methods للـ Customer:** محتاجين نعرف إزاي الـ Customer يجيب طرق دفع التاجر. هل لازم endpoint عام؟ ولا نجيبها من السيشن؟ لازم توضيح من الباك إند.
